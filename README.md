sql-analytics-lab
SQL queries for analytics and product data exploration.

Overview  
This repository contains SQL snippets commonly used for data analysis, reporting, and product metric tracking.  
Each query demonstrates practical use cases for understanding revenue, user engagement, and retention.

Example Queries  
- Top customers by total spend  
- Monthly revenue trends  
- Category-level average order value  
- Daily active users  
- Conversion rate by channel  

Tools  
PostgreSQL • SQL  

Use Cases  
These examples can be used as templates for dashboards, product analytics, or A/B testing pipelines.
